# Biforcom MCR-102 — OpenWrt 25.12.5

Образ для **MCR-102 с тремя LAN-портами** на Orange Pi Zero (Allwinner H2+).
Аппаратные настройки сверены с `rc.local`, `board.json` и DTB из
[Harwesta v1.13](https://github.com/Harwesta/Biforcom-MCR-routers/releases/tag/v1.13).
Используется штатная загрузка Orange Pi Zero из OpenWrt 25.12.5.

- LAN: `eth0 eth1 eth2` в `br-lan`, два LAN9514.
- USB: включены дополнительные хост-контроллеры EHCI/OHCI 2 и 3, как в DTB v1.13.
- Питание модемов: PA10 (GPIO10), затем PA13 (GPIO13) через 5 секунд.
  Один образ подходит для плат с одним и двумя установленными модемами:
  сетевые интерфейсы настраиваются через LuCI, без фиксированного APN или номера
  `cdc-wdm`. Отложенный перезапуск QMI пропускает отсутствующие устройства,
  а firewall перезапускается после появления IPv4.
- Русский LuCI, luci-app-5gmodem, OpenVPN с DCO и модули ядра для установки Podkop,
  как в сборке MCR-202. Podkop устанавливается отдельно.
- Автоматическое переключение SIM при потере интернета не настраивается.

Сборка: `./builder-mcr102/build.sh` на Linux или GitHub Actions в ветке
`mcr102-openwrt-25.12.5`. В артефакте Actions: образ microSD, конфигурация и SHA256.
Для первого запуска используй отдельную microSD с чистыми настройками.
Проверь холодный запуск, все три LAN-порта, каждый установленный модем и LAN → LTE.
